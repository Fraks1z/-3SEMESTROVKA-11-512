# 2-3 дерево – моя курсовая работа (1 курс)

## Что это такое?

мы сделали программу на Python, которая реализует **2-3 дерево**. Это такая структура данных, которая всегда остаётся сбалансированной. В ней можно быстро добавлять, искать и удалять числа. Все операции работают за O(log n) – это значит, что даже если данных очень много, то время работы растёт не сильно.

Код умеет:
- Генерировать 10 000 случайных чисел и сохранять их в файл.
- Вставлять эти числа в дерево и замерять, сколько времени и сравнений это занимает.
- Искать 100 случайных чисел и тоже замерять.
- Удалять 1000 случайных чисел.
- Строить графики, чтобы сравнить теорию (логарифм) с практикой.
- Сохранять все результаты в текстовый файл и картинку с графиками.

## Как запустить?

1. Установите Python (я использовал версию 3.10, но подойдёт любая 3.7+).
2. Установите библиотеку matplotlib – она нужна для графиков. Откройте терминал (командную строку) и напишите: pip install matplotlib
3. Скачайте файл `main.py` (весь код, который я приложил).
4. Запустите скрипт: python main.py
5. Дождитесь окончания работы. Программа сама создаст папку `meanings/`, внутри неё файл `input_data.txt` с 10000 чисел, а ещё в той же папке, где лежит `main.py`, появятся файлы:
- `results.txt` – таблица со средним временем и сравнениями.
- `analysis.png` – графики.
